# Changelog

Changes describe source versions. A version heading does not imply that a hosted service, binary release or package has been published.

## 0.1.0

Initial browser-local application:

- Raster-photo input, manual material and defect boundaries, and two-point calibration.
- Rectangular parts with quantities and optional 90° rotation.
- Deterministic bounded nesting with clearance and search-grid settings.
- Placement results, utilization and unplaced quantities.
- Version-1 project JSON, measured SVG, and tiled A4 print output.
- Core and browser-workflow tests, an included sample, and English documentation.

The planner is heuristic. Physical measurements and printed scale require independent verification. See [the guide](docs/guide.md) and [verification boundary](docs/testing.md).
